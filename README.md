# Маяк

Карта жизни: все цели на одной интерактивной карте — от главной вершины до сегодняшнего шага.

Статический сайт, сборка не нужна. Открывается как обычная веб-страница,
ставится на телефон как приложение, работает без интернета.

## Публикация

GitHub Pages: Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root` → Save.

## Файлы

- `index.html` — приложение целиком
- `manifest.json` — имя и иконка при установке
- `sw.js` — офлайн-режим
- `icon.svg` — логотип
